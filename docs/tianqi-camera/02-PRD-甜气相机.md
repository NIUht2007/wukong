# 甜气相机 PRD（V1.0 · MVP）

> 版本：V1.0 MVP ｜ 平台：**Android**（Flutter，仅 Android 构建）｜ 日期：2026-08

---

## 1. 产品定位

一句话：**一款甜系少女风的拍照拼图 App，随手拍、一键拼、甜度拉满。**

- 目标用户：16-28 岁女性，喜欢分享日常到朋友圈/小红书/微博
- 核心价值：甜系审美（滤镜/贴纸/模板风格统一）+ 拼图体验极简（3 步出图：选模板 → 放照片 → 导出）
- 差异化：不做大而全的修图工具，只做"甜"这一个风格方向，做到审美统一、开箱即用

## 2. 设计基调

甜系少女风：奶油粉、蜜桃色为主色，低饱和、大圆角、多留白、圆体字、微拟物贴纸。具体色值与规范见 `04-素材与设计规范.md`。**所有界面和素材必须遵守该规范，禁止出现高饱和蓝紫渐变。**

## 3. 一期功能范围（4 大模块）

### 3.1 拍摄与导入
- 相机拍摄：前置/后置切换、闪光灯开关、1:1 / 3:4 / 9:16 拍摄画幅切换
- 相册导入：系统相册多选（1-9 张），支持 HEIC/JPG/PNG
- 权限处理：相机/相册权限被拒时给出友好引导弹窗（附"去设置"按钮）

### 3.2 滤镜
- 一期内置 **10 款甜系滤镜**（名称可调整）：奶油、蜜桃、樱粉、薄荷、甜橙、胶片甜、奶杏、云朵、蜜茶、莓果
- 实现方式：LUT 色彩映射表或矩阵调色，**滤镜强度 0-100 滑杆可调**
- 滤镜缩略图实时预览，点击即应用
- 每张图片可独立设置滤镜（拼图内各图滤镜可以不同）

### 3.3 拼图模板
- 模板库按图片数量分类：2 图 / 3 图 / 4 图 / 6 图 / 9 图，每类 ≥ 3 种版式，一期共 ≥ 15 套模板
- 模板类型：规则宫格 + 异形布局（如一大两小、竖排电影感）+ 长图拼接
- 画布比例：1:1、3:4、4:3、9:16 可切换
- 编辑能力：
  - 点击槽位替换图片；双指缩放/拖动调整图在槽位内的取景
  - 边框粗细（0-40px）、边框圆角（0-40px）、间距可调
  - 背景：纯色（甜系色板）/ 渐变 / 模糊背景
  - 单张图可单独加滤镜、旋转、镜像

### 3.4 贴纸 / 文字 / 涂鸦
- 贴纸：内置 ≥ 20 枚甜系贴纸；支持双指缩放、旋转、拖动、删除、调整图层顺序
- 文字：自定义内容、字体（≥ 3 款）、颜色、描边、阴影、透明度、对齐
- 涂鸦：画笔颜色（甜系色板）、粗细、橡皮擦、撤销/重做
- 所有装饰元素统一走"可拖拽图层"交互模型

### 3.5 美颜（基础版）
- 磨皮（表面模糊保边）、美白（亮度曲线）、红润，各 0-100 滑杆
- 瘦脸、大眼：基于人脸关键点的网格液化，0-100 滑杆
- 美颜仅作用于人像拍摄/编辑场景；人脸检测失败时提示"未检测到人脸"
- 一期目标：自然不假面，参数默认值保守

## 4. 页面结构

```
首页（Home）
 ├─ 拍照入口（大按钮）
 ├─ 拼图入口（大按钮，进入模板选择）
 └─ 我的作品（本地草稿/历史导出缩略图）

拍照页（Camera）→ 拍完进入单图编辑页
模板选择页（TemplatePicker）→ 选图 → 拼图编辑页
拼图编辑页（CollageEditor）
 ├─ 顶部：撤销/重做、导出
 ├─ 中部：拼图画布
 └─ 底部 Tab：布局 | 边框 | 背景 | 滤镜 | 贴纸 | 文字 | 涂鸦
单图编辑页（PhotoEditor）
 └─ 底部 Tab：滤镜 | 美颜 | 贴纸 | 文字 | 涂鸦
导出页（Export）：保存到相册 / 系统分享
```

## 5. 非功能性需求

- 导出分辨率：最长边 ≥ 2560px，JPEG 质量 90，支持 PNG 选项
- 性能：9 图拼图编辑页操作帧率 ≥ 30fps（中端机）；图片加载全部走缩略图+原图分级
- 隐私：**全部图像处理在本地完成，不上传任何照片**；隐私政策中明确声明
- 崩溃率目标 < 0.5%；接入 Firebase Crashlytics 或同等免费方案
- 适配：Android 8.0+（minSdk 26）；刘海屏/挖孔屏、全面屏手势安全区；主流分辨率适配

| 功能 | 验收标准 |
|---|---|
| 拍摄导入 | 真机拍摄+多选导入成功；权限拒绝有引导；HEIC 正常解码 |
| 滤镜 | 10 款滤镜实时预览流畅，强度调节生效，导出与预览一致 |
| 拼图 | 15 套模板全部可用；改边框/圆角/背景实时生效；9 图操作不卡 |
| 贴纸文字涂鸦 | 三种元素可叠加、可撤销重做；导出合成位置与预览一致 |
| 美颜 | 磨皮/美白/瘦脸/大眼四滑杆生效；无人脸时有提示；不崩 |
| 导出分享 | 2560px 导出成功、进相册；系统分享面板可调起微信/小红书 |

- 不做视频编辑、GIF、Live Photo
