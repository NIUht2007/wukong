# 甜气相机 · 素材与设计规范

> 这份文件同时给你（找素材用）和 Kimi Code（写 UI 用）。所有界面、素材、图标必须遵守本规范。

---

## 一、品牌色板（写入 App 主题，色值不要改）

| 用途 | 名称 | 色值 |
|---|---|---|
| 主色 Primary | 甜粉 | `#FF9FB2` |
| 辅助色 Secondary | 蜜桃 | `#FFC9A3` |
| 强调 Accent | 莓果红 | `#F2708A` |
| 页面背景 | 奶白 | `#FFF9F7` |
| 卡片背景 | 纯白 | `#FFFFFF` |
| 浅填充/分隔 | 奶杏 | `#FFE9E4` |
| 正文文字 | 可可棕 | `#4A3B38` |
| 次要文字 | 灰粉棕 | `#A08E8B` |
| 点缀（少量用） | 薄荷 | `#BFE3D5` |

**规则：**
- 允许渐变仅限同族色系（甜粉 → 蜜桃 → 奶杏），角度 135°
- **禁止高饱和蓝紫渐变、禁止大面积深色背景**
- 整体低饱和、暖调、明亮；深色模式一期不做

## 二、形状与排版

- 圆角：大卡片 24px，小卡片/按钮 16px，主按钮胶囊形（999px），图片槽位默认 12px
- 阴影：只用柔和弥散阴影（透明度 ≤ 10%，模糊 ≥ 16px），禁止硬阴影
- 间距：页面左右边距 20px，卡片间距 16px，内容区留白充足
- 图标：线性风、2px 描边、圆角端点（如 Lucide / Remix Icon 风格）
- 字体（免费可商用，任选组合）：
  - 标题/装饰：**站酷快乐体** 或 **站酷高端黑**（站酷系列字体免费可商用）
  - 正文：**思源黑体** / **阿里巴巴普惠体**（均免费可商用）
  - 下载后把字体授权说明文件一并存入 `assets/fonts/` 存档

## 三、需要准备的素材清单

### 3.1 必备（开工第一周备齐）

| 素材 | 规格 | 说明 |
|---|---|---|
| App 图标 | 1024×1024 PNG，方形无圆角 | Android 自适应图标：前景图（安全区内）+ 甜粉纯色背景层 |
| 启动页 Logo | 居中图形 ≤ 400×400 | 奶白背景 + 品牌图形 |
| 贴纸包 ≥20 枚 | PNG 透明底，512×512 | 分类：蝴蝶结/爱心/星星/腮红/手绘线条/文字气泡/小动物 |
| 测试照片 5-10 张 | 人像+食物+宠物+风景 | 调滤镜和美颜用 |
| 隐私政策模板 | Markdown | 可让 Kimi Code 起草初稿 |

### 3.2 素材从哪来（免费可商用渠道）

- **图标**：iconfont.cn（阿里图标库，注意单图授权）、Lucide.dev（MIT）、Remix Icon（Apache 2.0）
- **插画/贴纸**：unDraw（免费可商用）、Open Doodles、Flaticon（免费档需署名，建议付费或仅作灵感自己画）
- **字体**：站酷字体官网（站酷快乐体等）、思源黑体（GitHub 开源）、阿里巴巴普惠体官网
- **测试图**：Pexels / Unsplash（免费可商用）
- **AI 生成**：贴纸也可以用 AI 绘图生成（透明底 PNG，提示词如 "cute pink bow sticker, flat illustration, white outline, transparent background"），风格最统一，推荐

> 占位策略：素材没齐之前，让 Kimi Code 用 Flutter 自绘/纯色块占位（提示词里已写），素材到位后替换 `assets/` 同名文件即可，不动代码。

## 四、关键页面视觉描述（Kimi Code 的 UI 依据）

### 首页
奶白背景。顶部左对齐大号标题"甜气相机"（站酷快乐体，可可棕）+ 副标题"随手拍，甜甜拼"（灰粉棕小字）。下方两张圆角大卡片上下排列：
- 「拍一张」：甜粉 → 蜜桃渐变底，白色相机线性图标，右下小箭头
- 「拼个图」：奶杏底 + 甜粉描边，四宫格线性图标
底部"我的作品"：横向滑动圆角缩略图（圆角 16px），空态显示浅虚线框 + "还没有作品，去拍第一张吧～"

### 编辑页通用
- 顶部栏：左侧返回、中间页面名、右侧"导出"胶囊按钮（主色填充白字）
- 画布区居中，四周留白；底部功能 Tab（图标+文字），选中态主色
- 二级面板从底部弹出，圆角 24px 顶边，高度 ≤ 屏高 40%
- 滑杆：主色轨道、白色圆形滑块带浅阴影

### 文案语气
甜而不腻，如："选几张喜欢的照片吧"、"拼好啦，快保存下来"、"未检测到小脸蛋哦"。按钮/提示文案全部口语化、带"～"和"吧/呀"适度使用。
