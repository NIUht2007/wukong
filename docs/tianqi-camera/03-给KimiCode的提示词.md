# 给 Kimi Code 的提示词（甜气相机 · Android · Flutter）

## 使用方法（重要，先读）

1. 在电脑上新建项目文件夹，如 `tianqi_camera`。
2. 把 `02-PRD-甜气相机.md` 和 `04-素材与设计规范.md` 两个文件**复制进项目文件夹**（提示词里会引用它们）。
3. 按顺序执行下面的 Prompt 0 → 7，**一次只发一个**，跑通验收标准后再发下一个。
4. 每个阶段验收通过后执行 `git add . && git commit -m "阶段X完成"`。
5. 报错了就把完整报错日志原样贴给 Kimi Code，加一句"请定位原因并修复"。

## Prompt 3 · 拼图模板引擎（核心模块，最难的一关）

```text
本阶段实现拼图模块（02-PRD 第 3.3 节），这是本 App 的核心，请设计好架构再动手。

任务：
1. 模板数据结构：用 JSON 描述模板（画布比例、槽位列表：每个槽位的 x/y/宽高比例、圆角、旋转角）。模板与代码解耦，新增模板只加 JSON 不改代码
2. 内置 ≥15 套模板：2图×3、3图×4、4图×4、6图×2、9图×2，含规则宫格、一大两小异形、竖排长图
3. 模板选择页：按图片数量分组展示模板缩略图（用占位色块实时渲染）
4. 拼图编辑页：
   - 画布比例切换 1:1 / 3:4 / 4:3 / 9:16
   - 点击槽位换图；双指缩放、拖动调整单图在槽位内取景；单图旋转、镜像
   - 边框粗细 0-40px、圆角 0-40px、槽位间距滑杆
   - 背景：甜系纯色色板 / 粉蜜桃系渐变 / 高斯模糊背景
   - 单图独立滤镜（复用上一阶段滤镜引擎）
5. 渲染方案：编辑态用 Widget 树（InteractiveViewer 缩放查看），导出态用离屏 Canvas 按 2560px 长边重绘，保证导出高清且与预览一致

验收标准：
- 15 套模板全部可用，切换模板图片自动填槽
- 9 图拼图中端机操作 ≥30fps
- 所有边框/圆角/背景调整实时预览
- 导出 2560px 图与预览构图完全一致
```

```text
本阶段实现美颜模块（02-PRD 第 3.5 节），接入单图编辑页。一期只要基础版，默认参数保守、效果自然。

1. 人脸检测：用 google_mlkit_face_detection 获取人脸关键点（轮廓、眼睛）

验收标准：
- 四项调节均生效且强度 30 以下观感自然不假面
```
