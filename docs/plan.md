# Plan：甜气相机 App — 给 Kimi Code 的开工准备包

## 目标
用户想用 Kimi Code 开发「甜气相机」（拍照拼图类 App），需要：
1. 一份清晰的准备清单（环境/账号/素材/决策项）
2. 可直接喂给 Kimi Code 的分阶段提示词
3. 配套 PRD（产品需求文档）与设计规范，作为 Kimi Code 的上下文输入

## 阶段
- Stage 0 — 需求澄清（ask_user）：目标平台、一期核心功能范围
- Stage 1 — 材料撰写（无匹配技能，由 Orchestrator 直接产出）：
  - `01-准备清单.md`：开发前需要准备/决策的所有事项
  - `02-PRD-甜气相机.md`：功能清单、页面结构、用户流程、验收标准
  - `03-给KimiCode的提示词.md`：分阶段 prompt（项目初始化 → 核心功能 → UI 打磨 → 迭代），可直接复制使用
  - `04-素材与设计规范.md`：配色、字体、图标、贴纸素材来源清单
- Stage 2 — 校验与交付：检查文件完整性，汇总交付并附使用说明
